あなたは git worktree 内で動く自動化エージェントです。
顧客ごとのメール本文抽出ルールを作成してください。

# 対象
customer_id: $customer_id
サンプルメール:
  $fixture_paths
抽出コマンド: $extract_command

# タスク
1. サンプルメールを読み、ノイズパターンを特定
2. extractors/$customer_id.yaml を作成
3. 抽出を実行し、結果を確認
4. OKになるまで調整

# ノイズの例（参考）
- 署名ブロック（--, Best regards, 氏名・部署・電話番号）
- 免責事項、配信停止リンク
- URLだけの行
- 引用（>）、転送ヘッダ
- 罫線（━、─、＝）

# 完了条件
- 本文として自然で、途中で切れていない
- 上記ノイズが残っていない
- 非空行が1行以上

# extractor のスキーマ
extractors/$customer_id.yaml は以下の形式:

customer_id: "$customer_id"
stop_markers:
  - "この文字列が出たら以降を全削除"
drop_line_regex:
  - "この正規表現にマッチする行を削除"

# ルール
1) extractors/$customer_id.yaml を作成・編集すること
2) previews/$customer_id.txt は手で編集しない（抽出コマンドで生成）
3) 迷ったら PASS にしない。保守的に FAIL として改善を続ける
4) extractor は最小限・読みやすく

# 作業手順（PDCA）
1. extractors/$customer_id.yaml を作成
2. $extract_command を実行
3. previews/$customer_id.txt を確認
4. 完了条件を満たすまで 1-3 を繰り返す
